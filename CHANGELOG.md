# Changelog

## v1.0.0 — 2026-11-16

- First public standalone release.
- Automatic detection of the CDI source folder.
- Automatic creation of the `CHD` output folder.
- Automatic use of `tools\cdirip.exe` and `tools\chdman.exe`.
- Incomplete CHD files are deleted automatically after a failed conversion.
- Normal percentage updates and tool banners are omitted from the log.
- Useful summaries and error diagnostics are retained.
- Logs are stored in `journal\cdi2chd_log.txt`.
- English documentation included.
